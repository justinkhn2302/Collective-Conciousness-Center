CCC COLLECTION UPDATE

INSTALL
1. Make a backup of your current ccc-site folder.
2. Extract this ZIP to a separate folder.
3. Copy index.html, styles.css, and script.js into your existing ccc-site folder and replace those three files.
4. Copy assets/products/products.json into the existing assets/products folder and replace products.json.
5. Copy each included description.txt into its matching numbered product folder if you want the text copies kept in sync.
6. Keep all existing product images, videos, and the four background/archive images in place. This update ZIP does not include or replace those media files.
7. Open index.html in Chrome. Refresh an already-open preview with Ctrl+F5.

EDITING
The page contains static product cards so it works by double-clicking index.html, without a local server. products.json is the matching catalog/reference; editing JSON alone will not change the cards. Update the matching card in index.html as well, or provide the revised catalog for a synchronized update.
